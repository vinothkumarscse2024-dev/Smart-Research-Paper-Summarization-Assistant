# Contributing

Thanks for helping improve this student project.

1. Create a virtual environment and install `requirements.txt` plus `pip install -e .`.
2. Keep API keys, PDFs, and local `data/` files out of commits.
3. Add or update tests for behavior changes. Use `python -m pytest -q` before opening a pull request.
4. Keep generated summaries and answers grounded in the extracted source; cite page numbers from the actual retrieved passages and expose uncertainty.
5. Open a pull request with a short description of the change and test results.
